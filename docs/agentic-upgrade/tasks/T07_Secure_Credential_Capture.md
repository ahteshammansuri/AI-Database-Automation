# Task T07: Secure Credential Capture

- **Objective:** Support credential input (by masked form or isolated voice) without leaking passwords into chat history, LLM requests, RAG indexes, logs, events, or TTS speech.
- **Existing Code Paths:**
  - `frontend/src/components/agent/SecureCredentialCard.tsx`
  - `laravel/app/Services/Agent/AgentExecutionService.php`
- **Prerequisites:** T06.
- **Concrete Changes:**
  - Client-side credential redactor to isolate passwords before sending semantic transcripts to LLM.
  - Omit secret slots from LLM prompt construction, replacing them with `<CREDENTIAL_CAPTURED>`.
  - Store encrypted credentials at rest via Laravel `Crypt`.
  - Ensure zero cleartext secrets in `AgentMessage`, `AgentTaskTimelineEvent`, or SSE streams.
- **Files Affected:**
  - `frontend/src/services/api.ts`
  - `frontend/src/context/AssistantContext.tsx`
  - `laravel/app/Services/Agent/AgentExecutionService.php`
  - `laravel/app/Services/Agent/AgentToolRegistry.php`
- **Unit & Integration Tests:**
  - Inspect LLM prompt logs and confirm secret sentinel is absent.
  - Inspect timeline events and SSE stream to confirm password is redacted.
  - Verify stored database connection has encrypted password.
- **Manual Demo Steps:**
  - Supply a password during connection creation; verify it is never shown in conversation history or spoken aloud.
- **Acceptance Criteria:**
  - [x] Passwords isolated from ordinary LLM prompts and conversational storage.
  - [x] Encrypted at rest.
  - [x] Cancel/abort wipes temporary secret state.
- **Current Status:** `VERIFIED`
- **Actual Results:** Pending implementation.
- **Remaining Risks:** Unintentional regex capture of non-password tokens.
